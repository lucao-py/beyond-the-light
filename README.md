# beyond-the-light
Exploring distant worlds through Machine Learning. A supervised learning project using NASA Kepler data to classify exoplanet signals and false positives.

## Dataset
- Source: [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/)
- Table: Kepler Objects of Interest (KOI) — Cumulative
- Extraction date: 2026-11-23

To download the dataset, run from the repository root:

    python src/ingestion.py

The original dataset snapshot is stored separately
from the repository to ensure reproducibility.
